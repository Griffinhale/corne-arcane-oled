# M11.5 protocol and data-flow acceptance record

> Historical milestone record. The accepted M13 two-half run on 2026-07-15
> supersedes the open M11.5 release gate. Its unchecked items remain an honest
> record of what was not separately signed off at v8, not current project work.

M11.5 was implemented on branch `m11.5-protocol-dataflow` from the merged M11.1
candidate. At that milestone it was desktop-verified but not separately
physically accepted. The M11.1 physical gate had been explicitly waived only to
begin the work and was not inherited as evidence for v8.

## Implemented workstreams

### Canonical firmware pipeline

- `duel_view_t` is an exact 18-byte pure projection from `sim_world_t`. The
  master renderer and split packet consume it directly; the slave renders an
  accepted view without reconstructing a fake mechanics world.
- HP and shield pairs are packed behind named checked accessors. View validation
  rejects every reserved-bit or out-of-range representation.
- `duel_render_t` is at most 32 bytes and stores the canonical view plus packed
  host/presentation fields, not a 56-byte world.
- The event queue is exactly 18 bytes: sixteen one-byte edge records, count, and
  separate saturating overflow. Cached matrix rows supply levels/scry; a
  catch-up run samples levels and drains the queued edge batch once.
- Host firmware retains `external` and `alert` as its canonical packed form.
  Release state omits protocol/diagnostic counters.
- Seqlock consumers reject odd or unchanged producer versions before copying.
  A slave decodes/copies only newly accepted snapshots.

### Protocol v8 and split scheduling

- The split packet is an exact 27-byte fixed, absolute, CRC-8-protected v8
  snapshot: six-byte header, 18-byte view, `external`, `alert`, and CRC. Bytes
  27-31 remain unallocated.
- Version mismatch, corruption, duplicate, reorder, loss, reboot/session change,
  sequence wrap, and stale-link convergence remain deterministic and tested.
- Active semantic changes transmit within 80 ms start-to-start; effects,
  display transitions, and host changes are urgent. Static healthy state checks
  its 250 ms absolute repair deadline independently of the 40 ms sim tick.
- `ARCANE_FIXED_SPLIT_CADENCE=yes` restores an 80 ms static repair heartbeat
  without changing the packet or receiver. This is the physical A/B control;
  adaptive cadence is not finally accepted until that comparison passes.
- Diagnostic builds use a fixed 16-byte reverse RPC reply containing accepted
  sequence, snapshot age, housekeeping/render peaks, queue overflow, missed
  resyncs, and stale transitions. Release builds use one-way sends and contain
  no `duel_diag` state.
- Diagnostic builds expose those reverse-RPC values and the master's complete
  counters as two CRC-protected 32-byte Raw HID response pages through
  `corne-arcane-diagnostics`. A request nonce prevents stale replies from being
  mistaken for the current sample. The response also identifies adaptive versus
  fixed-80 ms cadence; release builds omit the request staging and response path.

### Presentation scheduling

- Semantic equality is checked before composition. An unchanged static Duel
  performs no framebuffer clear, scene draw, or QMK buffer update.
- Presentation effects derive their remaining phase from monotonic elapsed
  time, so dim redraw cadence cannot stretch them.
- The only custom 512-byte framebuffer is already QMK page-major and is passed
  to `oled_write_raw()`; QMK owns final byte equality and dirty-block transfer.
- Existing exact logical framebuffer hashes remain unchanged.

### Host semantic pipeline

- One immutable, revisioned `SemanticState` resolves every source. One GLib
  scheduler uses focus, policy, adapter, HID heartbeat, and reconnect deadlines;
  the former 25 ms polling loop is gone.
- Notification replies/closes and focus reports wake the scheduler directly.
  Policy exposes transient-expiry and visible age-bucket deadlines.
- Notification parsing reads only required Variant children and selected hints.
  Privacy-safe counters cover matches, misses, replacements, closes, parse
  failures, high-water marks, and evictions.
- Application aliases resolve to a canonical profile before hashing. Profiles
  own scene, focused-suppression, and optional category policy.
- Five fail-soft adapters are wired: MPRIS, DND, systemd/Pomodoro,
  NetworkManager/VPN, and redacted Zsh/Git state. They reconcile current state
  once and then consume signals/deadlines; no adapter retains content or paths.

## Physical cadence A/B evidence

The corrected diagnostic scheduler was measured on both physical halves on
14 July 2026. Each active trace contains 50 Raw HID diagnostic samples while
typing continuously; the adaptive trace begins with four deliberate idle
samples, which account for its 249 ms maximum. Its steady active samples are
predominantly 78-80 ms, with a 79 ms median. A separate untouched ten-second
idle interval provides the comparable transaction-work result.

| Metric | Adaptive 250 ms repair | Fixed 80 ms repair |
| --- | ---: | ---: |
| Active samples / invalid peer samples | 50 / 0 | 50 / 0 |
| Active median snapshot age | 79 ms | 79 ms |
| Intended idle snapshot age | 249 ms | 80 ms |
| Idle successful split transfers / 10 s | 65 | 126 |
| Idle transfer reduction | 48.4% | control |
| Split failures / queue overflow | 0 / 0 | 0 / 0 |
| Missed resync / stale events | 0 / 0 | 0 / 0 |
| Master housekeeping peak (includes RPC) | 2,946 us | 3,071 us |
| Split transaction peak | 2,716 us | 2,809 us |
| Peer housekeeping / render peak | 291 / 577 us | 327 / 531 us |

Adaptive therefore preserves active latency and all recovery/error gates while
nearly halving observed idle split work. It is selected for the release build;
`ARCANE_FIXED_SPLIT_CADENCE=yes` remains the rollback control.

## Required physical acceptance

Do not claim final M11.5 acceptance until every item below is recorded. Flash
left and right separately from the same artifact with TRRS disconnected and USB
power removed before every cable change.

- [x] Flash both halves with the adaptive diagnostic pair; confirm boot, typing,
  v8 convergence, correct side/orientation, and no stale marker.
- [ ] Record master transaction peak/success/failure and slave accepted sequence,
  active snapshot age (<100 ms), housekeeping (<2 ms), render+blit (<5 ms),
  overflow, missed resync, and stale-transition counters.
- [ ] Run simultaneous two-half typing plus Raw-HID/notification/Git event flood;
  require zero queue overflow, missed resync, starvation, and unexpected stale
  transitions.
- [x] Repeat the same trace with the fixed-cadence diagnostic pair. Keep adaptive
  repair only if it reduces transaction work without weakening age, wake, or
  recovery; otherwise build release with `ARCANE_FIXED_SPLIT_CADENCE=yes`.
- [ ] Verify either-half wake, synchronized dim/fade/five-minute sleep, and that
  sleeping host-only events never wake the panels.
- [ ] Verify impact 600 ms and deflect/fizzle 400 ms on real panels in active and
  dim phases.
- [ ] Exercise MPRIS, DND, the configured timer, NetworkManager/VPN, Git enums,
  notification replacement/close, daemon restart, HID unplug/reconnect, and
  monitor denial with no plaintext in logs or retained state.
- [ ] Exercise suspend/resume and cable-loss/recovery while typing; verify local
  fallback and clean absolute convergence.
- [ ] Flash the release v8 pair and repeat the smoke/stress sequence without the
  diagnostic overlay.
- [ ] Flash and verify the preserved rollback pair before final sign-off.
