# M11.1 resource and hot-path acceptance record

M11.1 is a hardening pass over the physically flashed M11 release candidate.
It does not add presentation or protocol scope. Desktop evidence and physical
evidence remain separate; this record cannot declare final acceptance from
desktop tests alone.

## Kickoff source of truth

- Branch: `m11.1-resource-hotpath`.
- Starting commit: `bb439d0f099bef624ff11329eafa3b7e52fcc104`.
- The starting tree was clean and exactly matched the expected M11 candidate.
- The companion `Corne_Arcane_M11_1_Audit_M11_5_M12_Planning.docx` was supplied
  after the kickoff path and read in full before runtime implementation.
- The audit's planning posture does not itself authorize M11.5/M12 work; the
  companion kickoff explicitly authorizes this bounded M11.1 implementation.
- The installed `griffin_hostoled` source matched the repository functionally.
  Expected differences were the host-only `rules.mk` overlay and README label;
  `sim_test/scenarios.h` differed only by a trailing blank line.

`make visual-test`, `make gallery`, and `make budget`. The gallery contained 37
canonical paired frames and the host suite passed 36/36 tests.

## Inherited QMK feature A/B audit

Every row below is a clean release build of the unchanged M11 source. Deltas
are measured against the reproduced baseline, not estimated.

| Build | Flash | `.data` | `.bss` | Static RAM | Flash delta | Static-RAM delta | Decision |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| Baseline | 50,120 | 3,576 | 10,204 | 13,780 | 0 | 0 | Reference |
| `WPM_ENABLE=no` | 49,820 | 3,572 | 10,148 | 13,720 | -300 | -60 | Disable; unused by firmware and UI |
| `RGBLIGHT_ENABLE=no` | 50,120 | 3,576 | 10,204 | 13,780 | 0 | 0 | Keep explicitly disabled; already inactive |
| `RGB_MATRIX_ENABLE=no` | 47,032 | 3,544 | 9,764 | 13,308 | -3,088 | -472 | Measured but retain; accepted layout exposes `RM_*` controls |
| All three disabled | 46,724 | 3,540 | 9,700 | 13,240 | -3,396 | -540 | Measured reference only |

The production decision preserves the existing RGB Matrix behavior as the
single intentional lighting engine, explicitly disables RGBLIGHT, and removes
unused WPM. This preserves the accepted compiled layout instead of silently
turning its RGB Matrix controls into no-ops.

## Acceptance status

Desktop tests, visual diff summary, final artifacts, and physical checks will
be added after the scoped implementation commits. Physical flash, either-half
wake, five-minute continuity, host-flood typing stress, suspend/resume,
split-link recovery, diagnostic timing, and rollback remain pending until run
on the keyboard.

The audit's recommended M11.5 A1-A4 work is intentionally deferred: diagnostic
backchannel, real-notification integration harness, canonical application
profiles, and event-driven host scheduling. No M12 living-stage art or game
expansion belongs on this branch.
